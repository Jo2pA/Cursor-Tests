# Cursor-Tests

静的な日本語ランディングページ「Future Vision」です。ビルドや依存関係はなく、ブラウザでそのまま開けます。

## 含まれるもの

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ本体。ホーム、アバウト、サービス、お問い合わせの各セクション |
| `style.css` | レイアウトと見た目 |
| `script.js` | モバイルメニュー、スムーズスクロール、スクロール時のナビ背景、パーティクル |

外部のパッケージは使いません。見出し用のフォントだけ、Google Fonts（Orbitron と Noto Sans JP）を読み込みます。

## 起動方法

ファイルを直接開く場合:

```bash
xdg-open index.html
```

ローカルで静的サーバーを立てる場合（パスやキャッシュの確認に向いています）:

```bash
python3 -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` を開きます。終了は `Ctrl+C` です。
